# **BlackHole**

> ## ✴️ **Functionalities**

   - Allows all staff member on your server to send message under **BlackHole**'s identity.
   - Create [custom polls](https://github.com/TheOnlyFloof/BlackHole/new/main?filename=README.md#-polls).


> ## ❔ **Polls**

  - Use '!poll 1 + argument' to get a Yes / No poll.
  - Use '!poll 2 + argument' to get a 1 to 10 poll.
  - Use '!poll_help' and the bot will mp you theses informations.
